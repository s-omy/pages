## 出典・訂正

これは過去の会話レポートの移植版です。各号の事実、日程、価格、企業の動向、製品仕様、URLは独立には再検証していません。
元レポートの「確認済み」などは当時の記述であり、この移植作業による確認を意味しません。
各ページに出典未検証の注記を設け、復元できない引用を「引用先未復元」に置換しています。
後続号に訂正がある場合も、以前の号の歴史的記述は残しています。判断前に公式情報を確認してください。

## 公開

ただしこのリポジトリには既存サイトとCloudflare関連設定があるため、公開方式を確認せず切り替えないでください。
