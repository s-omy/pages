# Security Policy

## Reporting a Vulnerability

セキュリティ上の問題を見つけた場合は、公開の Issue ではなく、次のアドレスへ連絡してください。

- Contact: report-to@oro-9.org

(For English: please report vulnerabilities privately by email to the address above rather than opening a public issue.)

## Scope

このリポジトリは `pages.oro-9.org` で公開している静的サイトのみを含みます。
個人運営のため、対応は best effort です。
